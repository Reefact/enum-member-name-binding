# Documentation utilisateur

🌍 **Langues :**  
🇫🇷 Français (ce fichier) | 🇬🇧 [English](README.md)

Tout ce que lit un consommateur des deux paquets. La [page d'accueil](../../README.fr.md) est le
chemin d'entrée le plus court ; ces pages sont la version intégrale de ce qu'elle résume.

| Page | Ce qu'elle répond |
|---|---|
| [Règles de contrat](contract-rules.fr.md) | ce qu'est un contrat, ce qu'il doit respecter, le comportement de `[Flags]` et des contrats partiels, et toutes les options |
| [Analyseurs](analyzers.fr.md) | les six diagnostics, ce que chacun attrape, et celui qui mérite deux lectures |
| [OpenAPI](openapi.fr.md) | faire décrire au document généré les valeurs que le serveur accepte réellement |
| [Limitations](limitations.fr.md) | ce que cette bibliothèque ne fait pas, et quoi écrire à la place |
| [Diagnostics](rules/README.fr.md) | une page par règle, vers laquelle pointe une erreur de build |
