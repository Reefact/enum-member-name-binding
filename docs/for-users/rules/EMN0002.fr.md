# EMN0002 — Le nom public est inutilisable

🌍 **Langues :**  
🇬🇧 [English](./EMN0002.en.md) | 🇫🇷 Français (ce fichier)

| | |
|---|---|
| **Sévérité** | Erreur |
| **Catégorie** | ApiContract |
| **Également appliqué** | au démarrage, par `EnumContractException` |

## Cause

Une valeur de `[JsonStringEnumMemberName]` est vide, ou commence ou finit par une espace.

<!-- emn:allow=EMN0002 -->
```csharp
public enum Status
{
    [JsonStringEnumMemberName("")]         Unknown,   // EMN0002
    [JsonStringEnumMemberName(" active ")] Active     // EMN0002
}
```

## Pourquoi c'est important

Un nom vide ne peut pas être distingué d'une valeur absente dans une chaîne de requête ou un champ de
formulaire : le membre ne pourrait donc jamais être sélectionné.

Un nom entouré d'espaces est pire qu'inutilisable — c'est un piège. `System.Text.Json` détoure la
valeur reçue avant de la comparer, si bien que `" active "` ne correspondrait jamais à un nom qui
contient lui-même les espaces. Le membre serait déclaré et pourtant inatteignable.

`System.Text.Json` lève une `InvalidOperationException` sur ces deux formes à la première utilisation.
Cette règle déplace cet échec à la compilation.

## Comment corriger

Utilisez un nom non vide, sans espaces autour. Les caractères internes sont libres, sauf la virgule
sur une énumération `[Flags]` — voir [EMN0004](EMN0004.fr.md).

```csharp
public enum Status
{
    [JsonStringEnumMemberName("unknown")] Unknown,
    [JsonStringEnumMemberName("active")]  Active
}
```

## Quand la supprimer

Jamais.
