# EMN0002 — The public name is not usable

🌍 **Languages:**  
🇬🇧 English (this file) | 🇫🇷 [Français](./EMN0002.fr.md)

| | |
|---|---|
| **Severity** | Error |
| **Category** | ApiContract |
| **Also enforced** | at start-up, by `EnumContractException` |

## Cause

A `[JsonStringEnumMemberName]` value is empty, or begins or ends with whitespace.

<!-- emn:allow=EMN0002 -->
```csharp
public enum Status
{
    [JsonStringEnumMemberName("")]         Unknown,   // EMN0002
    [JsonStringEnumMemberName(" active ")] Active     // EMN0002
}
```

## Why it matters

An empty name cannot be distinguished from an absent value on a query string or a form field, so the
member could never be selected.

A padded name is worse than unusable — it is a trap. `System.Text.Json` trims the value it receives
before matching, so `" active "` would never match a name that itself contains the spaces. The
member would be declared and yet unreachable.

`System.Text.Json` throws an `InvalidOperationException` on both shapes at first use. This rule moves
that failure to build time.

## How to fix

Use a non-empty name with no surrounding whitespace. Internal characters are unrestricted, except
for the comma — see [EMN0004](EMN0004.en.md).

```csharp
public enum Status
{
    [JsonStringEnumMemberName("unknown")] Unknown,
    [JsonStringEnumMemberName("active")]  Active
}
```

## When to suppress

Never.
