# EMN0004 — Un nom public sur une énumération `[Flags]` contient une virgule

🌍 **Langues :**  
🇬🇧 [English](./EMN0004.en.md) | 🇫🇷 Français (ce fichier)

| | |
|---|---|
| **Sévérité** | Erreur |
| **Catégorie** | ApiContract |
| **Également appliqué** | au démarrage, par `EnumContractException` |

## Cause

Un membre d'une énumération `[Flags]` déclare un nom public contenant une virgule.

<!-- emn:allow=EMN0004 -->
```csharp
[Flags]
public enum Scopes
{
    [JsonStringEnumMemberName("read,write")] ReadWrite = 3   // EMN0004
}
```

## Pourquoi c'est important

`System.Text.Json` refuse la forme purement et simplement : construire un convertisseur pour
l'énumération ci-dessus lève une `InvalidOperationException`, et le message le dit en toutes
lettres — *« Flags enums must **additionally** not contain commas »*. L'énumération ne peut donc pas
être sérialisée du tout, et cette règle transforme cet échec à l'exécution en erreur de compilation.

## Uniquement sur une énumération `[Flags]`

Cette règle a un temps signalé toutes les énumérations, sur l'idée qu'une virgule sépare des valeurs
partout, donc qu'un nom qui en porte une ne peut jamais être relu. La première moitié est vraie ; la
seconde n'en découle pas. Le sérialiseur cherche la valeur détourée **comme un seul nom avant de
découper quoi que ce soit** : sur une énumération ordinaire, un `news,world` déclaré s'écrit et se
relit :

```csharp
public enum Topic
{
    [JsonStringEnumMemberName("news,world")] NewsWorld = 4,
    [JsonStringEnumMemberName("news")]       News      = 1,
    [JsonStringEnumMemberName("world")]      World     = 2
}
```

`?value=news,world` lie `NewsWorld`, et non `News | World` — le nom l'emporte, parce qu'il est
cherché en premier. `?value=news, world` est la combinaison, car aucun nom ne s'écrit avec cette
espace : elle vaut `1 | 2`, qui ne nomme aucun membre, et elle est refusée comme n'importe quelle
autre combinaison de ce genre
([limitations](../limitations.fr.md#une-combinaison-qui-ne-nomme-aucun-membre-est-refusée-hors-du-corps)).

Signaler cette énumération revenait à refuser un contrat que le sérialiseur accepte, ce qui est la
seule chose que ce paquet n'a pas le droit de faire. La règle s'arrête désormais là où le
sérialiseur s'arrête.

## Comment corriger

Choisissez un nom sans virgule.

```csharp
[Flags]
public enum Scopes
{
    [JsonStringEnumMemberName("read")]       Read      = 1,
    [JsonStringEnumMemberName("write")]      Write     = 2,
    [JsonStringEnumMemberName("read_write")] ReadWrite = 3
}
```

## Quand la supprimer

Jamais. L'énumération ne peut pas être sérialisée par `System.Text.Json`, donc supprimer la règle ne
fait que déplacer l'échec à la première requête.
