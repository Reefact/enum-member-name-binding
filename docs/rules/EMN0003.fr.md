# EMN0003 — Le contrat de l'énumération est incomplet

🌍 **Langues :**  
🇬🇧 [English](./EMN0003.en.md) | 🇫🇷 Français (ce fichier)

| | |
|---|---|
| **Sévérité** | Erreur |
| **Catégorie** | ApiContract |
| **Également appliqué** | au démarrage, par `EnumContractException`, sauf si `AllowPartialContracts` est activé |

## Cause

Une énumération déclare un contrat — au moins un membre porte `[JsonStringEnumMemberName]` — mais
certains membres n'en portent pas.

```csharp
public enum Shipping
{
    [JsonStringEnumMemberName("express")] Express,
    Standard                                        // EMN0003
}
```

## Pourquoi c'est important

L'attribut **remplace** le nom d'un membre ; il n'ajoute pas un alias. Un membre laissé sans
annotation répond donc à son nom C#, et ce nom C# devient une partie de votre contrat d'API public :

```
GET /orders?mode=Standard   → 200
GET /orders?mode=standard   → 200
```

Renommer `Standard` dans votre code devient alors un changement cassant pour tous les appelants — ce
que déclarer un contrat explicite était précisément censé empêcher. Oublier un membre est une erreur,
pas un choix de conception : c'est donc signalé comme une erreur.

## Comment corriger

Annotez chaque membre.

```csharp
public enum Shipping
{
    [JsonStringEnumMemberName("express")]  Express,
    [JsonStringEnumMemberName("standard")] Standard
}
```

## Quand la supprimer

Quand l'énumération ne vous appartient pas — celle d'une dépendance, par exemple. Activez-le
explicitement à l'enregistrement :

```csharp
.AddEnumMemberNameBinding(options => options.AllowPartialContracts = true);
```

puis désactivez la règle, puisque l'analyseur ne voit pas votre configuration d'exécution :

```ini
[*.cs]
dotnet_diagnostic.EMN0003.severity = none
```

Gardez [EMN0005](EMN0005.fr.md) active. Une fois EMN0003 désactivée, c'est la seule règle qui vous
protège encore d'un nom déclaré masquant un membre non annoté.
