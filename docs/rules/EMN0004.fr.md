# EMN0004 — Un nom public `[Flags]` contient une virgule

🌍 **Langues :**  
🇬🇧 [English](./EMN0004.en.md) | 🇫🇷 Français (ce fichier)

| | |
|---|---|
| **Sévérité** | Erreur |
| **Catégorie** | ApiContract |
| **Également appliqué** | au démarrage, par `EnumContractException` |

## Cause

Un membre d'une énumération `[Flags]` déclare un nom public contenant une virgule.

```csharp
[Flags]
public enum Scopes
{
    [JsonStringEnumMemberName("read,write")] ReadWrite = 3   // EMN0004
}
```

## Pourquoi c'est important

Une valeur `[Flags]` s'exprime comme une liste séparée par des virgules — `read, write` signifie les
deux. Un nom qui contient lui-même une virgule ne peut pas être distingué d'une combinaison de deux
membres : la valeur peut être écrite, mais jamais relue.

`System.Text.Json` rejette la même forme à la première utilisation, pour la même raison.

La règle ne s'applique **pas** à une énumération sans `[Flags]`, où une virgule n'est qu'un caractère
ordinaire et où aucun découpage n'a lieu.

## Comment corriger

Choisissez un nom sans virgule.

```csharp
[Flags]
public enum Scopes
{
    [JsonStringEnumMemberName("read")]       Read      = 1,
    [JsonStringEnumMemberName("write")]      Write     = 2,
    [JsonStringEnumMemberName("read_write")] ReadWrite = 3
}
```

## Quand la supprimer

Jamais.
